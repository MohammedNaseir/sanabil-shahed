# مختبرات صقور الكيمياء | منصة سنابل التعليمية

الموقع: **https://sanabil-shahed.naseir.site**

منصة تعليمية تفاعلية لمنهاج الكيمياء للصف العاشر، إعداد وإشراف أ. شهد نصير:

- **مختبر السيليكون**: ست محطات ألعاب (سباق الصقور، فك الشيفرة، الدوارق، الفرن، المحقق، طوق النجاة).
- **مختبر بنية الذرة**: ست وجهات علمية، ودفتر الباحث، وشهادة إنجاز.
- **لوحة المعلمة**: اعتماد الطلاب، والنتائج المباشرة، والإعلانات، وفتح المختبر وإغلاقه.

## التصميم

- **الخطوط** مدمجة في المشروع (تعمل دون إنترنت): Cairo للعناوين، وTajawal للنصوص.
- **وضعان داكن وفاتح**: يتبع إعداد الجهاز افتراضياً، ويُحفظ اختيار الطالب من زر الشمس/القمر.
- **الألوان** في `src/theme-palette.css`: لوحة واحدة (ذهب شمبانيا، زنجار، ياقوت، عقيق على حبر دافئ) تنعكس تلقائياً في الوضع الفاتح.
- **الجوال**: شريط تنقّل سفلي، والنوافذ تنزلق من الأسفل.

## المتطلبات

- Node.js بالإصدار **20.19** أو أحدث (أو 22.12 فما فوق).

## التشغيل محلياً (وضع التطوير)

```bash
npm install
cp .env.example .env.local   # ثم ضعي رمز المعلمة في TEACHER_CODE
npm run dev
```

افتحي `http://localhost:3000`.

> **رمز المعلمة إلزامي.** لا يوجد رمز افتراضي داخل الكود. إذا لم يُضبط `TEACHER_CODE` يعمل المختبر للطلاب بشكل طبيعي، لكن دخول لوحة المعلمة يبقى معطّلاً، وتظهر رسالة توضّح السبب.

### متغيرات البيئة

| المتغير | مطلوب؟ | الوصف |
|---|---|---|
| `TEACHER_CODE` | نعم | رمز دخول لوحة المعلمة |
| `TEACHER_TOKEN_HOURS` | لا | مدة صلاحية جلسة المعلمة بالساعات (الافتراضي 8) |
| `PORT` | لا | منفذ الخادم (الافتراضي 3000) |
| `LAB_DATA_DIR` | لا | مجلد حفظ بيانات الطلاب (الافتراضي `./data`) |
| `TRUST_PROXY` | لا | عدد طبقات البروكسي إن كان الخادم خلف استضافة مثل Cloud Run أو Nginx (مثلاً 1) |

## النشر (وضع الإنتاج)

```bash
npm run build   # يبني الواجهة والخادم والنسخة المستقلة
npm start       # يشغّل dist-server/server.js في وضع الإنتاج
```

- شغّلي الأوامر من مجلد المشروع، فالخادم يقرأ `dist/` و `data/` نسبةً إليه.
- بيانات الطلاب تُحفظ في `data/lab-store.json`. **انسخيها احتياطياً** قبل أي تحديث أو نقل.
- جلسات المعلمة محفوظة في ذاكرة الخادم، لذلك تحتاج المعلمة تسجيل الدخول من جديد بعد إعادة تشغيله.

## النشر على Coolify (Docker Compose)

المشروع جاهز للنشر بملفي `Dockerfile` و `docker-compose.yml`.

1. ارفعي المشروع إلى مستودع Git (GitHub أو GitLab أو غيرهما).
2. في Coolify: **New Resource ← Application** واختاري المستودع، ثم **Build Pack: Docker Compose**.
3. في **Environment Variables** أضيفي `TEACHER_CODE` برمز طويل يصعب تخمينه. هذا المتغيّر إلزامي، والنشر يتوقف بدونه.
4. في إعدادات خدمة `app` ضعي الدومين `https://sanabil-shahed.naseir.site`. Coolify يتولى شهادة HTTPS والبروكسي.
5. اضغطي **Deploy**.

**البيانات:** محفوظة في volume اسمه `lab-data` (المسار `/app/data` داخل الحاوية)، ولا تضيع عند إعادة النشر أو التحديث. وفيه مجلد `backups/` بنسخة يومية ونسخة قبل كل «تصفير النقاط» أو حذف طالب (آخر 30 نسخة). يمكنك أيضاً تفعيل النسخ الاحتياطي للـ volume من Coolify.

**التجربة محلياً بنفس الإعداد:**

```bash
docker build -t shhd-labs .
docker run -p 3000:3000 -e TEACHER_CODE=رمز-تجريبي -v shhd-data:/app/data shhd-labs
```

## النسخة المستقلة (ملف HTML واحد)

```bash
npm run build:standalone
```

ينتج الملف `dist-standalone/مختبر_الأسئلة_صقور_أ_شهد.html` (نحو 2.3MB)، وفيه كل الكود والصور، ويعمل دون خادم. يمكن تنزيله أيضاً من زر «تحميل ملف HTML» في لوحة المعلمة.

**حدود النسخة المستقلة:** كل الأنشطة والتدريب تعمل، والنتائج تُحفظ على جهاز الطالب فقط («وضع التدريب دون اتصال»). أما التسجيل لدى المعلمة ولوحة الشرف ولوحة المعلمة فتحتاج الخادم. الخطوط مدمجة داخل الملف، فيعمل كاملاً دون إنترنت.

## تسجيل الطلاب

- يسجّل الطالب **اسمه الثلاثي ورقماً سرياً يختاره بنفسه** (4 إلى 6 أرقام، بالأرقام العربية أو اللاتينية). لا يحتاج أي رقم هوية.
- رقم الطالب في المختبر (مثل `SQR-Si-4821`) يولّده الخادم تلقائياً.
- للدخول من جهاز آخر: الاسم نفسه والرقم السري نفسه.
- الرقم السري محفوظ مُجزّأً (hash) لا نصاً، وبعد 5 محاولات خاطئة يُقفل الدخول بذلك الاسم 15 دقيقة.
- إن نسي الطالب رقمه: من لوحة المعلمة ← «الطلاب في المختبر» ← زر المفتاح بجانب اسمه. يظهر رقم جديد مرة واحدة لتعطيه للطالب.
- إغلاق المختبر يمنع التسجيلات الجديدة فقط، والطلاب المسجّلون يستطيعون الدخول.

## كيف تُحفظ النتائج

- كل نتيجة تُحفظ أولاً على جهاز الطالب، ثم تُرسل للخادم عبر طابور يعيد المحاولة تلقائياً إذا انقطع الاتصال. يظهر تحت اسم الطالب في الشريط العلوي: «تم الحفظ» أو «غير متصل» أو «بانتظار اعتماد المعلمة».
- لا يقبل الخادم النقاط قبل أن تعتمد المعلمة الطالب، وتبقى النقاط محفوظة على الجهاز لحين الاعتماد.
- نقاط مختبر الذرة تُحتسب على الخادم من قائمة المهام المعروفة فقط، ولكل مهمة مرة واحدة.
- عند «تصفير جميع النقاط» من لوحة المعلمة، تُرفض أي نتيجة أقدم من التصفير حتى لو وصلت متأخرة.
- التقدّم داخل كل لعبة يُحفظ، فإذا خرج الطالب أو انقطع الاتصال يكمل من حيث توقف، أو يختار «ابدأ من جديد».
